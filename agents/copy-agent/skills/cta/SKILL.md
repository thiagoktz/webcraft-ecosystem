# Skill: CTA — Calls to Action que Convertem

---

## O que faz um CTA funcionar

Um CTA converte quando elimina três barreiras:
1. **Fricção** — o próximo passo parece complicado ou custoso
2. **Risco** — o usuário teme errar ou se comprometer demais
3. **Vagueza** — não está claro o que vai acontecer ao clicar

---

## Fórmula base

```
[Verbo de ação] + [Objeto específico] + [Redutor de risco opcional]

"Agendar"    + "avaliação"    + "gratuita"
"Ver"        + "planos"       + "sem precisar de cartão"
"Baixar"     + "o guia"      + "grátis"
"Começar"    + "agora"       + "cancele quando quiser"
```

---

## Hierarquia de CTAs por página

Toda página deve ter no máximo 2 tipos de CTA:

```
CTA Primário (1 por página)
→ A ação principal que você quer que o usuário faça
→ Botão sólido, cor de destaque, posição privilegiada
→ Ex: "Agendar avaliação gratuita"

CTA Secundário (1-2 por página)
→ Para quem ainda não está pronto para o primário
→ Botão outline ou link de texto
→ Ex: "Ver como funciona" / "Conhecer os planos"
```

**Nunca competir:** CTA primário e secundário nunca devem ter o mesmo peso visual.

## CTAs por etapa da jornada

### Topo do funil (descoberta) — usuário ainda não confia
```
✅ "Ver como funciona"
✅ "Conhecer os serviços"
✅ "Baixar guia gratuito"
✅ "Assistir demonstração"
❌ "Comprar agora" (muito cedo)
❌ "Fale com vendas" (intimidador)
```

### Meio do funil (consideração) — usuário está avaliando
```
✅ "Agendar conversa gratuita"
✅ "Ver planos e preços"
✅ "Começar teste grátis"
✅ "Solicitar proposta"
❌ "Saiba mais" (muito vago)
```

### Fundo do funil (decisão) — usuário está pronto
```
✅ "Contratar agora"
✅ "Começar hoje"
✅ "Fazer meu pedido"
✅ "Garantir minha vaga"
❌ "Entre em contato" (muito fraco para esse momento)
```

## Redutores de risco por tipo de negócio

| Contexto | Redutor eficaz |
|---|---|
| Serviço com consulta | "sem compromisso" / "gratuita" |
| SaaS | "cancele quando quiser" / "sem cartão de crédito" |
| E-commerce | "frete grátis" / "troca grátis em 30 dias" |
| Infoproduto | "garantia de 7 dias" |
| Serviço de saúde | "avaliação gratuita" / "sem fila de espera" |
| B2B | "sem contrato de fidelidade" / "proposta em 24h" |

## CTAs para contextos específicos

### WhatsApp (muito comum no Brasil):
```
✅ "Chamar no WhatsApp"
✅ "Falar agora pelo WhatsApp"
✅ "Tirar dúvidas pelo WhatsApp"
❌ "Clique aqui" (genérico)
```

### Formulário de contato:
```
Botão de submit nunca deve dizer "Enviar" — diga o que acontece depois:
✅ "Quero ser contactado"
✅ "Enviar mensagem"
✅ "Solicitar retorno"
❌ "Submit" / "Send" / "Ok"
```

### Download:
```
✅ "Baixar o guia gratuito"
✅ "Quero o material"
✅ "Acessar agora"
❌ "Download" (frio e técnico)
```

### Agendamento:
```
✅ "Escolher meu horário"
✅ "Marcar consulta"
✅ "Reservar minha vaga"
❌ "Agendar" (funciona, mas pode ser mais específico)
```

## Microcopy ao redor do CTA

O texto logo abaixo ou ao lado do botão é tão importante quanto o botão:

```
[Botão: "Começar teste grátis"]
Sem cartão de crédito · Cancele quando quiser · Suporte em português

[Botão: "Agendar avaliação"]
Resposta em até 2 horas · Atendemos de segunda a sábado

[Botão: "Baixar o guia"]
PDF gratuito · 23 páginas · Enviado direto para seu e-mail
```

## Checklist de CTA

- [ ] Verbo de ação presente (não "saiba mais" ou "clique aqui")
- [ ] Objeto específico (o que o usuário vai receber ou fazer)
- [ ] Redutor de risco adequado ao contexto
- [ ] Máximo 1 CTA primário por página
- [ ] CTA secundário com peso visual menor
- [ ] Microcopy reforça a decisão (abaixo do botão)
- [ ] Tom consistente com o restante da página
- [ ] Texto do botão de formulário descreve o que acontece após clicar
- [ ] CTAs de WhatsApp com linguagem de conversa, não de formulário
