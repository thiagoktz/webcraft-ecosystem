# Skill: Copywriting — Textos que Convertem

---

## Princípios fundamentais

### 1. O leitor decide em 3 segundos
O hero precisa responder imediatamente: "Isso é para mim?" Se não responder, o usuário sai.

**Fórmula do hero:**
```
[Quem você ajuda] + [Problema que resolve] + [Resultado prometido]

Exemplo ruim:  "Soluções inovadoras para o seu negócio"
Exemplo bom:   "Fisioterapia para quem quer voltar a se mover sem dor"
```

### 2. Benefício antes de feature
```
Feature:   "Tecnologia de ultrassom de última geração"
Benefício: "Recuperação 40% mais rápida com tecnologia de ultrassom"

Regra: sempre responda "e daí?" antes de escrever.
"Temos 10 anos de experiência" → e daí? → "10 anos formando pacientes que voltaram à vida ativa"
```

### 3. Especificidade convence, generalidade não
```
❌ "Atendemos muitos pacientes satisfeitos"
✅ "Mais de 2.000 pacientes recuperaram sua mobilidade aqui"

❌ "Resultados rápidos"
✅ "Primeiros resultados em até 3 sessões"
```

### 4. Uma ideia por frase
```
❌ "Nossa clínica, fundada em 2014 por fisioterapeutas especializados que
    estudaram na USP, oferece tratamentos modernos e personalizados."

✅ "Nossa clínica foi fundada por fisioterapeutas formados na USP.
    Cada tratamento é personalizado para o seu caso."
```

### 5. CTA sempre acionável
```
❌ "Saiba mais" / "Clique aqui" / "Entre em contato"
✅ "Agendar avaliação gratuita" / "Ver planos" / "Falar com especialista"

Fórmula: verbo + objeto + redutor de risco
"Agendar" + "avaliação" + "gratuita"
```

## Estruturas por seção

### Hero — fórmula PAS (Problema → Agitação → Solução)
```
P: "Convive com dor crônica que não passa?"         ← problema
A: "Tratamentos genéricos que ignoram seu caso?"    ← agitação
S: "Fisioterapia personalizada que trata a causa."  ← solução

Ou fórmula direta (para negócios estabelecidos):
[Resultado desejado] + [Para quem] + [Como]
"Recupere sua mobilidade — fisioterapia personalizada para dores crônicas"
```

### Features/Serviços — fórmula FAB
```
Feature:  O que é
Advantage: O que faz de diferente
Benefit:  O que significa para o cliente

Exemplo:
F: "Fisioterapia neurológica"
A: "Protocolo adaptado ao histórico de cada paciente"
B: "Recuperação mais completa para quem passou por AVC ou cirurgia"
```

### Sobre — fórmula do propósito
```
Por que existimos → Como fazemos → O que entregamos

"Criamos a Saúde Total porque vimos pacientes desistirem de tratamentos
que não explicavam o porquê de cada decisão. Nossa missão é tratar
com transparência — você entende cada etapa da sua recuperação."
```

### Depoimentos — estrutura antes/depois
```
[Situação antes] + [O que mudou] + [Resultado específico]

"Passei 2 anos com dor lombar sem conseguir trabalhar direito.
Depois de 3 meses na Saúde Total, voltei a correr e reduzi os
analgésicos completamente." — Ricardo M., analista de sistemas
```

### CTA final — fórmula de próximo passo
```
[Benefício resumido] + [Próximo passo claro] + [Redutor de risco]

"Sua recuperação começa com uma conversa.
Agende sua avaliação gratuita — sem compromisso."
```

## Palavras que convertem vs. que afastam

### Usar:
- você, seu, sua (foco no leitor)
- porque (justifica)
- imagine, descubra (ativa)
- grátis, gratuito, sem custo (reduz risco)
- resultado, recuperação, transformação (orientado a outcome)
- garantido, comprovado (credibilidade)
- agora, hoje, rápido (urgência real)

### Evitar:
- nós somos líderes / referência / pioneiros
- soluções inovadoras / de ponta
- excelência, qualidade, comprometimento (vazios)
- entre em contato (fraco)
- bem-vindo ao nosso site
- somos apaixonados por
- mais de X anos no mercado (sem contexto)

## Limites de caracteres por elemento

| Elemento | Limite | Por quê |
|---|---|---|
| Título H1 | 60 chars | SEO + legibilidade mobile |
| Subtítulo hero | 120 chars | 2 linhas em mobile |
| CTA principal | 30 chars | Cabe no botão |
| Meta title | 60 chars | Google trunca além disso |
| Meta description | 160 chars | Google trunca além disso |
| Card de serviço | 80 chars | Consistência no grid |
| Depoimento | 200 chars | Legível sem expandir |

## Checklist de copywriting

- [ ] Hero responde "isso é para mim?" em 3 segundos
- [ ] Benefício mencionado antes da feature em cada seção
- [ ] Números específicos onde possível (não "muitos", mas "2.000+")
- [ ] Zero frases genéricas ("excelência", "soluções inovadoras")
- [ ] CTA com verbo de ação + objeto + redutor de risco
- [ ] Linguagem do público-alvo (não jargão interno)
- [ ] Depoimentos com contexto real (nome + situação)
- [ ] Cada seção tem uma função única — sem repetição de mensagem
- [ ] Limites de caracteres respeitados
