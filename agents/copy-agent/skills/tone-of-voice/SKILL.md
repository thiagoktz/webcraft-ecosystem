# Skill: Tone of Voice — Voz e Tom da Marca

---

## O que é tom de voz (e o que não é)

**Tom de voz** é como a marca fala — sua personalidade expressa em palavras.
**Não é** o conteúdo do que fala, mas a maneira como fala.

A mesma mensagem em toms diferentes:
```
Mensagem: "Temos horários flexíveis"

Tom formal:      "Oferecemos agendamento em horários estendidos para sua conveniência."
Tom acolhedor:   "A gente se adapta à sua rotina — tem horário que funcione melhor pra você?"
Tom direto:      "Atendemos de segunda a sábado, das 7h às 20h. Escolha o seu horário."
Tom premium:     "Atendimento nos horários que se encaixam na sua agenda."
```

## Os 5 tons principais e como escrever em cada um

### 1. Profissional
**Marcas:** consultorias, escritórios de advocacia, serviços B2B, financeiras
**Características:** direto, confiante, sem gírias, dados e fatos, respeita o tempo do leitor

```
✅ "Reduzimos o tempo de recuperação em 40% com protocolo baseado em evidências."
✅ "Três etapas. Um resultado mensurável."
❌ "A gente tá aqui pra te ajudar a crescer!"
❌ "Nossa paixão é ver você evoluir 🚀"

Estrutura preferida: afirmação + dado + implicação
Pontuação: frases curtas, sem exclamações
Pronome: "você" (não "tu", não "vocês")
```

### 2. Acolhedor
**Marcas:** saúde, educação, bem-estar, terapia, ONGs
**Características:** empático, próximo, usa "você", valida o sentimento antes de oferecer solução

```
✅ "Sabemos que conviver com dor crônica é exaustivo. Estamos aqui para mudar isso."
✅ "Cada paciente tem um ritmo. Respeitamos o seu."
❌ "Nossa missão é prover soluções terapêuticas de alta performance."
❌ "Venha nos conhecer e descubra nossos tratamentos!"

Estrutura preferida: reconhecimento + empatia + solução
Pontuação: frases médias, 1-2 exclamações no máximo por página
Pronome: "você", "a gente" (informal controlado)
```

### 3. Técnico
**Marcas:** SaaS, tecnologia, engenharia, medicina especializada, indústria
**Características:** preciso, usa termos do setor, assume conhecimento do leitor, dados antes de emoção

```
✅ "API RESTful com autenticação OAuth 2.0 e rate limit de 1.000 req/min."
✅ "Compatível com DICOM 3.0 e integração nativa com sistemas HIS/RIS."
❌ "Nossa plataforma super fácil de usar vai transformar seu jeito de trabalhar!"
❌ "Tecnologia de ponta para o seu negócio crescer."

Estrutura preferida: especificação + contexto + impacto técnico
Pontuação: sem exclamações, listas técnicas quando necessário
Pronome: "você" ou impessoal ("o sistema", "a plataforma")
```

### 4. Descontraído
**Marcas:** alimentação, moda jovem, entretenimento, apps de lifestyle, startups consumer
**Características:** informal, humor leve, conversacional, referencias culturais, energia positiva

```
✅ "Sério, esse brownie vai mudar sua semana."
✅ "Feito pra quem não tem tempo — mas tem gosto."
❌ "Oferecemos produtos de confeitaria artesanal de alta qualidade."
❌ "Nossa empresa foi fundada com o objetivo de..."

Estrutura preferida: conversa direta, como uma mensagem de amigo
Pontuação: reticências para pausas, travessão para ênfase, 1-2 emojis estratégicos
Pronome: "você", "tu" (se o público for muito jovem)
```

### 5. Premium
**Marcas:** luxo, moda de alto padrão, arquitetura, hotéis 5 estrelas, finanças private
**Características:** elegante, econômico em palavras, sem superlativos baratos, mostra em vez de dizer

```
✅ "Feito à mão. Entregue em 72 horas."
✅ "Cada projeto começa com uma conversa."
❌ "O melhor atendimento premium de luxo que você já viu!"
❌ "Somos referência em excelência e qualidade inigualável."

Estrutura preferida: afirmação simples e confiante — sem justificar
Pontuação: frases muito curtas, sem exclamações, zero emojis
Pronome: "você" (discreto, não excessivo)
```

## Consistência entre seções

O tom não muda de seção para seção — muda apenas a intensidade:

| Seção | Intensidade | Por quê |
|---|---|---|
| Hero | Alta | Precisa capturar imediatamente |
| Features | Média | Informar sem perder energia |
| Sobre | Humana | Momento de conexão pessoal |
| Depoimentos | Neutra | A voz é do cliente, não da marca |
| CTA final | Alta | Momento de conversão |
| Footer | Baixa | Utilitário — não precisa convencer |

---

## Detector de inconsistência de tom

Ao revisar os textos gerados, verificar:

```
1. Pronome consistente? (não misturar "você" e "vocês")
2. Nível de formalidade consistente? (não misturar "a gente" com "prezado cliente")
3. Exclamações dentro do limite? (máx 2 por página em tom acolhedor, 0 em premium)
4. Jargão técnico adequado ao público? (não usar "KPI" para público leigo)
5. Tamanho das frases consistente? (premium = curtas, acolhedor = médias)
```

## Tom por segmento — referência rápida

| Segmento | Tom primário | Tom secundário |
|---|---|---|
| Saúde / Clínica | Acolhedor | Profissional |
| SaaS / Tech | Profissional | Técnico |
| Alimentação | Descontraído | Acolhedor |
| Educação | Acolhedor | Profissional |
| Jurídico | Profissional | — |
| Moda premium | Premium | — |
| E-commerce jovem | Descontraído | — |
| Consultoria B2B | Profissional | Técnico |
| Academia / Fitness | Descontraído | Acolhedor |

---

## Checklist de tom de voz

- [ ] Tom definido antes de escrever qualquer texto
- [ ] Pronome consistente em todas as seções
- [ ] Nível de formalidade não varia entre seções
- [ ] Exclamações dentro do limite do tom
- [ ] Zero frases que contradizem o tom (ex: "incrível!!!" em tom premium)
- [ ] Depoimentos preservam a voz do cliente (não reescrever no tom da marca)
- [ ] Tom salvo no Memory Agent para uso em projetos futuros do cliente
